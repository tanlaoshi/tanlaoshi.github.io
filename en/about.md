ToyOS exists because teaching needs a system that is **readable and changeable end to end**: from UEFI boot to desktop and user ELFs, with clear layer boundaries — so class can point at code, not a black box demo.

What we deliberately skip: chasing Linux userspace compatibility; making TTF the default text path; building a phone product; productizing Secure Boot. Class time is finite; a tight boundary is how “runs / changeable / teachable” stays real.

Author: **Tan Yugang** (Teacher Tan). Talks and demos: [Bilibili](https://space.bilibili.com/41036636).
